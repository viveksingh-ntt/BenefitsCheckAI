# `.gitignore`

Source: [`.gitignore`](../../../.gitignore)

> **Summary:** Keeps local and secret files out of git: Python caches, `.env` files, SQLite databases (`*.db` and WAL files), `dev-keys/`, virtual environments, `node_modules/` and `dist/`.

Commit only the `.env.example` templates. Real settings live in the container apps' environments and in Key Vault.
