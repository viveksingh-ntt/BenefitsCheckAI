> **Summary:** Example environment for running `host_agui.py` outside the local stack script.

| | |
| --- | --- |
| Layer | Agent relay (AG-UI path) |

It lists the `relay.factory` variables plus `BROKER_ISSUER`, `BROKER_JWKS_URL` and `AGUI_CORS_ORIGINS`. In Azure these are Container App settings (see [AG-UI](../../../../ag-ui.md)).
