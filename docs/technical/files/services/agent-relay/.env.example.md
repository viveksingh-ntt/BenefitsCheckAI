# `services/agent-relay/.env.example`

Source: [`services/agent-relay/.env.example`](../../../../../services/agent-relay/.env.example)

> **Summary:** A documented template of every environment variable the relay reads, with local defaults and the Azure value in a comment beside each.

Sections:

- **M365 Agents SDK connection:** the bot identity (`CONNECTIONS__SERVICE_CONNECTION__SETTINGS__*`).
- **HealthGen services:** the broker and MCP URLs and credentials.
- **Foundry through APIM:** base URL, credential, agent name and version, timeout.
- **`dev_server.py` only:** `DIRECTLINE_SECRET` and `DEV_CORS_ORIGINS`.

Copy it to `.env` for manual runs; `.env` is git-ignored. `scripts/local_stack.py` sets the same values itself. In Azure, set them on the container app (runbook steps 5, 8 and 10). Don't put secrets in this file.
