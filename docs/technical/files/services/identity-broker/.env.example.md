# `services/identity-broker/.env.example`

Source: [`services/identity-broker/.env.example`](../../../../../services/identity-broker/.env.example)

> **Summary:** A template of every broker setting, with local defaults and Azure alternatives in comments.

| Group | Variables |
| --- | --- |
| Issuer | `BROKER_ISSUER` (public base URL; the `iss` of every token) |
| Signing | `BROKER_KEYVAULT_KEY_ID` and `AZURE_CLIENT_ID` (Azure), or `BROKER_SIGNING_KEY_FILE` (dev) |
| Direct Line | `DIRECTLINE_SECRET`, `DIRECTLINE_ENDPOINT`, `DIRECTLINE_TRUSTED_ORIGINS` |
| Portal assertions | `PORTAL_ISSUERS`, `PORTAL_JWKS_URL` |
| Service auth | `SERVICE_AUTH=keys` with `SERVICE_KEYS` (dev), or `SERVICE_AUTH=entra` with `ENTRA_TENANT_ID`, `BROKER_ENTRA_AUDIENCES` and `SERVICE_CLIENTS` |
| State and lifetimes | `BROKER_DB_PATH`, `SESSION_IDLE_SECONDS`, `SESSION_MAX_SECONDS`, `USER_CONTEXT_AUDIENCE` |

In Azure the Direct Line secret is a Key Vault reference (`secretref:directline-secret`, runbook step 10), never a literal value.
