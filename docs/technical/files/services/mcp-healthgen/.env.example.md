# `services/mcp-healthgen/.env.example`

Source: [`services/mcp-healthgen/.env.example`](../../../../../services/mcp-healthgen/.env.example)

> **Summary:** A template of the MCP server's settings: upstream URLs, broker credential, inbound auth for `/mcp` and `/internal`, allowed hosts and the hand-off webhook.

| Group | Variables |
| --- | --- |
| Upstreams | `BROKER_URL`, `CORE_URL` |
| To the broker | `BROKER_CLIENT_KEY` (dev), or `BROKER_ENTRA_RESOURCE` and `AZURE_CLIENT_ID` |
| `/mcp` callers | `MCP_AUTH`, plus `MCP_KEYS` or `ENTRA_TENANT_ID`, `MCP_AUDIENCES` and `MCP_CLIENTS` |
| `/internal` callers | `INTERNAL_AUTH`, plus `INTERNAL_KEYS` or `INTERNAL_AUDIENCES` and `INTERNAL_CLIENTS` |
| Transport | `MCP_ALLOWED_HOSTS` |
| Hand-off | `HANDOFF_WEBHOOK_URL`, `HANDOFF_WEBHOOK_SECRET` (Key Vault reference in Azure) |
